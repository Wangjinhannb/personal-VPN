# Generic Ubuntu VPS / 通用 Ubuntu VPS

## English

Confirm that the provider offers a public IPv4 address and a working global IPv6 address with a default route. Open inbound UDP `51820` in the provider firewall. Provider-specific anti-spoofing, routed-prefix, and forwarding policies may apply. The toolkit cannot override provider-side restrictions.

## 中文

确认服务商提供公网 IPv4，以及具备默认路由的可用全球 IPv6 地址。在服务商防火墙开放入站 UDP `51820`。服务商可能存在反欺骗、路由前缀和转发策略限制，部署工具无法绕过服务商侧限制。
